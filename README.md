# Muhammed Nabeel Abdurrauf Portfolio

Static GitHub Pages portfolio built with plain HTML and CSS.

## Files

- `index.html` contains the website content.
- `styles.css` contains the responsive visual design.
- `script.js` contains the light/dark theme toggle.
- `assets/profile.jpeg` is the public profile image copied from `my.jpeg`.
- `assets/thesis-image.png` and `assets/stability-anchored-image.png` are local project figures.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Set the source to the main branch and root folder.
4. Save and wait for GitHub Pages to publish the site.

## Content Notes

The site intentionally avoids linking private documents, transcripts, ID/residence files,
reference emails, phone numbers, and raw application letters. Replace project placeholders
inside `index.html` with public images or links when they are ready to share.
